# CodeGrind

    Gamify your coding with language XP, levels, and real-time stats.

    ## Features

    - **Real-Time Tracking**: Tracks typed characters grouped by file extensions (`.tsx`, `.stories.tsx`, `.scss`,

`.json`, etc.). - **Sidebar Webview**: Interactive React-based dashboard in the VS Code / VS Codium sidebar. - **Persistent Storage**: Your stats are saved locally and persist across restarts and different projects.

    ## How to Use

    1. Click on the CodeGrind icon in the Activity Bar on the left.
    2. Open any file in your project and start coding.
    3. Watch your character count update live in the sidebar!
